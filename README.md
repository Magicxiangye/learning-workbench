# 学习工作台

一个静态学习工作台，支持书架、逐课阅读、进度筛选、笔记和续读。状态保存在当前浏览器。

## 本地运行

```sh
python3 -m http.server 8000 --directory dist
```

在浏览器中打开 `http://localhost:8000`。应用无需安装依赖。

## 课程数据

`dist/courses.js` 提供可独立运行的原创示例课程。每本书包含唯一 ID、标题、主题、学习路线和课节列表；每节课包含唯一 ID、标题和 Markdown 正文。进度通过课节 ID 关联。新增课程时为每节课保留稳定的 ID。

正式课程与私人部署配置保存在独立的私有项目中。
